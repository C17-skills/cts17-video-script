# 商单流程

1. 先读广告方的要求文档，列出：可选玩法、硬性要求（必须说的话、必须出现的画面、话题顺序）、结算方式、截止时间。
2. 挑玩法：用户手上有没有对应设备 → 前后对比明不明显 → 参考视频的数据。按播放量结算就往大众痛点上靠。
3. 提示风险：查这个产品或玩法有没有翻车的新闻；涉及删文件、装第三方软件的，提醒先备份、先私下跑一遍。
4. 写稿：按教程骨架出三栏脚本；广告方的硬性话术原样放进去，其余用用户本人的口气。
5. 效果数字只用实拍的，稿子里先留【待补】。
6. 发布：按平台要求加广告标识；完整指令放评论区置顶；话题按广告方给的顺序带。
7. 商单内容和用户公开说过的立场打架时直说，由用户决定接不接。
