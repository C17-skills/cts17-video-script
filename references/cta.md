# 结尾 CTA 和变现

CTA 就是结尾让观众做的那一个动作。一条视频只放一个，按任务选。

| 任务 | CTA 类型 | 写法方向 | 前提 |
|---|---|---|---|
| 破圈、随拍 | 互动提问 | "你们觉得呢？评论区说说" | 问题一句话能答 |
| 拿线索 | 评论区扣字领取 | "我整理好了，评论区扣'XX'，我发你" | 资料已经做好；有人及时回复 |
| 教程、商单 | 置顶评论 | "完整指令我放评论区置顶了" | 发布后马上置顶 |
| 干货 | 催行动 | "这个方法抓紧时间试一下" | — |
| 涨粉 | 关注理由 | 说清关注后能持续看到什么 | 只承诺已经在做的内容 |
| 转化 | 主页 / 私信 | "想让我帮你看看的，主页找我" | 主页已有承接入口 |
| 随拍、情绪类 | 不放 | 重复一遍情绪就停 | — |

## 规则
- 写成用户本人的口气，优先用 `voice.md` 里他用过的收尾。
- CTA 前一句给理由：为什么现在就要做这个动作。
- 不承诺没定的后续内容。
- 口播、字幕、评论区不出现微信号、"加我 V"这类站外导流话术，用"主页""私信""评论区"。
- 领取类 CTA 先查 `account.md`：资料不存在就换别的类型，并提醒用户先把资料做出来。
- 营销和成交不放在同一条里。

## 变现承接
按 `account.md` 里的产品阶梯走，一般是：免费资料 → 低价入门 → 主力产品 → 高价服务。视频只负责把人带到下一级，不在视频里讲完所有产品。
