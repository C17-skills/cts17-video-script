# 开头（前 3～5 秒）

## 硬标准
- 第一句不超过 20 个字，3 秒内说完。
- 5 秒内观众要知道：这是讲给谁的、看完能得到什么。
- 第一句同时写好画面（第一眼看到什么）和大字（屏幕上的字，不超过 8 个字）。
- 开头说的结果，正文必须兑现；数字必须是真的。

## 句式库（每次出 5 个，各用不同的）

| 句式 | 写法 | 示意 |
|---|---|---|
| 身份 + 处境 + 具体数字 | 我是谁、现在在干什么、带一个数 | "毕业不找工作，带着一万块，折腾的第 20 天" |
| 戳现状 + 反问 | 先说观众的处境，再问一句 | "一个学校能搜出一两百个同类账号，你真的卷得过吗？" |
| 点名人群 + 硬建议 | 所有想做 X 的人，都去做 Y | "我建议所有想做 X 的人，都去做一张 Y" |
| 点名人群 + 真的不要再…… | 劝退一个常见做法 | "做 X 的人，真的不要再 Y 了" |
| 刚花的钱 + 情绪 | 花了多少、现在什么心情 | "昨天花了 140 块开了会员，我后悔了" |
| 一个状态 + 一个数字 | 正在发生的事 | "已经安全用了 48 小时，没出问题" |
| 情绪直说（随拍） | 第一句就是情绪 | "朋友们，我失策了" |
| 接话式（随拍） | 像在回应别人 | "不是，你们怎么都在问我……" |
| 结果前置 + 如何 | 先亮结果 | "如何一天让五六百个人主动找你" |
| 结果前置 + 意外 | 结果加没想到 | "我靠 X 赚到第一个一万，一开始根本没想到它能赚钱" |
| 自己的反差 | 以前的我和现在的我 | "读了这么多年书，才发现自己很幼稚" |
| 具体对比 | 两个数字放一起 | "你累死累活拿的奖学金，人家一个暑假就赚到了" |
| 眼前的麻烦（教程） | 观众此刻的问题 | "你的 C 盘是不是也红了" |

`profile/voice.md` 里有"对这个号有效的开头句式"时，先用那几种。

## 叠加元素（至少 2 个）
跟我有关、具体数字、可信的身份、想要的结果、怕发生的事、反常识、正在发生。

## 三个检验（过不了就重写）
1. 遮住测试：只看第一句，陌生人知道在讲什么吗？会停下吗？
2. 像他测试：这句话用户本人会这么说吗？
3. 兑现测试：正文真能给出开头承诺的东西吗？

## 不要的开头
打招呼和自我介绍；"今天聊一个话题"；让观众猜；"你知道吗"；"钩子 + 痛点 + 承诺"三件套原样堆满；和正文对不上的标题党。
